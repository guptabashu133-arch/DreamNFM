# Ready-to-use plugin jars

Every Dream plugin, latest build. Click a file, then **Download raw file**
(the download button at the top right). `all-plugins.zip` has all of them.

| File | Version | Plugin |
|---|---|---|
| `Dreamcrates.jar` | 2.0.0 | Crates on map screens: spin/select, 25 crate looks, keys, history, leaderboard, store page, daily free crate, pity, key trading |
| `Dreamkoth.jar` | 3.0.0 | King of the Hill: CAPTURE/SCORE, schedules, 3D crowns with buffs, koth screen |
| `Dreamteams.jar` | 2.0.0 | Teams: bank, home, allies, team chat, PVP toggle, screens |
| `Dreamcoinshop.jar` | 2.1.0 | Coin shop with wall screens |
| `Dreamleaderboard.jar` | 1.2.0 | Leaderboards on map screens |
| `Dreamrtp.jar` | 3.2 | Random teleport with dialog, /rtpback, screen |
| `Dreamrtpqueue.jar` | 2.0.0 | RTP queue (1v1 random teleport) |
| `Dreamtab.jar` | 1.1.1 | Tab list |
| `DreamScreens.jar` | 1.1.0 | Map touchscreens + in-game editor, holograms, NPCs |
| `Dreammultiverse.jar` | 1.0.0 | World manager |
| `DreamWorldEdit.jar` | 1.0.0 | WorldEdit/FAWE-style editing |
| `DreamEngine.jar` | 1.0.0 | Economy + built-in Vault, staff tools, kits, rollback, rename |
