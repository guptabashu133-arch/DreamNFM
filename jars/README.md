# Ready-to-use plugin jars

Built from the `claude/festive-tesla-f8ycg5` branches of each repo. Click a file, then **Download raw file** (the download button at the top right).

| File | Plugin |
|---|---|
| `DreamScreens.jar` | Map touchscreens + in-game editor, holograms, NPCs (needs a Dreamscube license key) |
| `Dreammultiverse.jar` | Multiverse-style world manager (Folia too) |
| `DreamWorldEdit.jar` | WorldEdit/FAWE-style editing |
| `DreamEngine.jar` | Economy + built-in Vault, staff tools, kits, rollback, rename |
| `all-plugins.zip` | All four in one zip |
